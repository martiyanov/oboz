# Веб-версия «Обозревателя» — контракт API и требования к интерфейсу

Веб-версия — тонкая оболочка над тем же ядром (`src/digest.js`): никакой второй логики оценки,
никаких внешних CDN и зависимостей. Сервер — `web/server.mjs` (Node, `node:http`), статика —
`web/public/` (`index.html`, `app.js`, `style.css`, `favicon.svg`).

Публичный адрес: `https://agonarena.ru/oboz/` (nginx снимает префикс `/oboz/`, приложение видит
корень `/`). Поэтому **все запросы из браузера — относительные** (`api/digest`, `app.js`), без
ведущего `/`: так страница работает и локально (`http://127.0.0.1:8788/`), и под префиксом.

## Эндпоинты

### `GET /api/digest?region=ru|world|all&threshold=0.55&limit=12&refresh=1`

`threshold` округляется сервером до шага 0.05 и ограничивается 0.3…0.95; `limit` — 6…30.
`refresh=1` игнорирует серверный кэш (не чаще одного пересчёта в 30 секунд).

```json
{
  "generatedAt": 1794130000000,
  "region": "ru",
  "threshold": 0.55,
  "empty": false,
  "stats": {
    "articlesUsed": 944, "events": 442, "passed": 45, "shown": 12,
    "sourcesOk": 20, "sourcesTotal": 20, "sourcesFailed": 0,
    "demo": false, "clusters": 787
  },
  "meta": {
    "minDomains": 2, "minConfidence": 0.5,
    "weights": { "severity": 0.4, "corroboration": 0.25, "recency": 0.15, "confidence": 0.2 },
    "regions": { "ru": "Россия", "world": "Мир", "all": "Всё" }
  },
  "passed": [Event],
  "rejected": [{ "id": "a1b2c3d4", "title": "…", "score": 0.53, "reasons": ["…"] }]
}
```

`passed` — только события выше порога и с подтверждениями (уже отфильтровано ядром), до `limit`
штук. `rejected` — до 12 ближайших отклонённых (для объяснения порога).

### `GET /api/event/<id>?region=ru|world|all`

Полное досье любого события (включая не прошедшие порог) с подгруженной справкой Википедии.
Ответ: `{ "event": Event }`. 404: `{ "error": "event not found" }`. Время ответа — до ~8 с
(сетевой запрос к Википедии; дальше кэш).

## Требования к интерфейсу (`web/public/`)

Файлы: `index.html`, `app.js`, `style.css`, `favicon.svg`. **Без npm, без CDN, без внешних
шрифтов и картинок** — только системные шрифты (`-apple-system, Segoe UI, Roboto…`) и инлайн SVG.

1. **Тёмная тема**, ощущение терминального обозревателя: моноширинный акцент для цифр/оценок,
   плотная вёрстка, спокойные цвета. Адаптивность до мобильного (≤ 640 px).
2. **Шапка**: название «ОБОЗРЕВАТЕЛЬ», переключатель региона `Россия / Мир / Всё`, слайдер
   порога (0.30…0.95, шаг 0.05, значение рядом), кнопка «Обновить», строка статистики
   (`источников 20/20 · публикаций 944 · событий 442 · прошло 45`), индикатор демо-данных.
3. **Список событий**: карточка с цветным бейджем оценки (`[0.92]`), заголовком, 2 строками
   summary, чипами источников, `N источников`, «X мин назад», метка «официальный первоисточник»,
   если `attribution.official`. Пустое состояние: крупно «Ничего существенного не произошло»,
   статистика и кнопка «снизить порог».
4. **Досье**: назад к списку; заголовок; оценка и достоверность; summary; блок «ТЕЗИСЫ»
   (нумерованные, с типом и цифрами); блок «ПОДТВЕРЖДЕНИЯ» (карточки: имя источника, тир
   «высокое/среднее/низкое доверие», время, заголовок, кнопка «Открыть оригинал» — `<a
   target="_blank" rel="noopener">`); блок «ПРОВЕРКА» (официальный первоисточник, расхождения
   в цифрах, осторожные формулировки, слагаемые оценки); блок «ВИКИПЕДИЯ» (карточки со ссылкой),
   если `wiki` пуст — «справка не найдена».
5. **Клавиатура** (как в терминале): `↑/↓` или `j/k` — движение по списку, `Enter` — открыть,
   `Esc` — назад, `r` — обновить, `o` — открыть первый/выбранный первоисточник, `?` — подсказка
   по клавишам (можно блок внизу). Клик мышью — тоже работает.
6. **URL**: состояние в hash — `#/event/<id>` для досье, параметры региона/порога — в `?region=…&threshold=…`
   (через `history.replaceState`), чтобы ссылка открывалась в том же виде.
7. **Живость**: автообновление списка раз в 60 с (пауза, когда открыто досье), обратный отсчёт
   не обязателен. Кнопка «Обновить» — с `refresh=1`. Во время загрузки — скелетоны/статус,
   ошибки — баннер с текстом и кнопкой «повторить». Пустой ответ API — штатное пустое состояние.
8. **Безопасность/этика**: только относительные API-запросы, никаких `eval`, `innerHTML` для
   приходящих с сервера строк (только `textContent`/`createElement`), все внешние ссылки
   `target="_blank" rel="noopener noreferrer"`, внизу подпись: «Подтверждение — это несколько
   независимых редакций, а не гарантия истины; Википедия — только фон».
9. **Доступность**: контраст ≥ 4.5, фокус видим, `aria-label` на переключателях, клавиатурная
   навигация без ловушек, `prefers-reduced-motion` отключает анимации.
10. **Без библиотек**: ванильный JS (ES2020), `fetch`, `URLSearchParams`, `Intl.RelativeTimeFormat`
    для «N мин назад» (с фолбэком).

Проверка: `node web/server.mjs` → открыть `http://127.0.0.1:8788/`, список должен загрузиться
без ошибок в консоли; API — `curl http://127.0.0.1:8788/api/digest?region=ru`.
